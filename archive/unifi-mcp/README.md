# UniFi Network MCP for ToolHive

This deploys only the [UniFi Network MCP server](https://github.com/sirkirby/unifi-mcp) (not the separate Protect or Access servers). ToolHive's `mcp-tools` group automatically adds it to the authenticated `mcp-gateway` VirtualMCPServer. The server binds HTTP on port 3000 behind ToolHive's proxy on port 8080; the backend itself has no HTTP authentication. `networkpolicy.yaml` permits backend ingress only from the operator-created `unifi-network` ToolHive proxy pod. Do not expose the backend Service through an Ingress/HTTPRoute.

Before reconciling, create **MCP_USERNAME** and **MCP_PASSWORD** fields in the existing `unifi` 1Password item for a dedicated _local_ UniFi service account. Upstream requires a local username/password for full Network API functionality; UniFi cloud SSO and accounts requiring MFA are not supported for this path. Assign only the controller permissions you want an AI assistant to have. The 1Password `EXTERNALDNS_KEY`, `UNPOLLER_KEY`, and `HOMEPAGE_KEY` are different API keys and are intentionally not reused. `unifi.ishioni.casa` is reached via the existing `${PRIVATE_DOMAIN}` substitution with HTTPS certificate verification enabled.

By default all create/update/delete actions are denied by the upstream Network policy gates, including when called through lazy meta-tools. The gateway still lists write tools, but invocations should fail authorization. To allow changes later, review upstream's [permission model](https://github.com/sirkirby/unifi-mcp/blob/main/apps/network/docs/permissions.md) and use a deliberately scoped controller account and category-specific policy overrides rather than removing the gates wholesale.

After Flux reconciliation, check the `unifi-mcp` Kustomization, the `unifi-mcp-credentials` ExternalSecret and Secret (containing `UNIFI_USERNAME` and `UNIFI_PASSWORD`), `unifi-network` MCPServer readiness, and the `mcp-gateway` discovery. Try a harmless `unifi_get_system_info` or `unifi_get_network_health` read. No controller mutations should be used for validation.
